# Archived project-page version

This folder preserves the earlier modular project-page layout for reference.
It is not included as a public route. The canonical site is the continuous
research-note layout in `app/page.tsx`.

`page.tsx` and `globals.css` are a reference-only migration snapshot. The
stylesheet is not imported by the published route; it intentionally retains
the historical selectors and later visual experiments that existed before the
active stylesheet was isolated.
